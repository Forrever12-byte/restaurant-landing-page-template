# 🍽️ Savora — Restaurant Landing Page Template

A modern, responsive landing page template built for Nigerian restaurants and food businesses. Designed and developed by **Forr3ver Dev**.

**🔗 Live Demo:** [forrever12-byte.github.io/restaurant-landing-page-template](https://forrever12-byte.github.io/restaurant-landing-page-template/)


---

## ✨ Features

- **Hero image carousel** — auto-rotating background images with smooth fade transitions
- **Responsive navbar** — transparent-to-solid on scroll, with an animated hamburger menu for mobile
- **Dynamic, filterable menu** — 36 sample dishes across 4 categories (Starters, Mains, Drinks, Desserts), rendered from a JS data array with click-to-filter category tabs
- **Photo gallery** — clean, responsive image grid
- **Testimonials section** — customer reviews with star ratings
- **Contact section** — address, phone, opening hours, and a map placeholder
- **WhatsApp integration** — "Call Us" buttons link directly to WhatsApp chat
- **Back-to-top button** — appears on scroll, smooth-scrolls to top
- **Fully mobile-first** — built with Nigerian mobile users in mind (compressed images, touch-friendly buttons, WhatsApp CTAs)

---

## 🛠️ Built With

- **HTML5**
- **Tailwind CSS v4** (local CLI build, not CDN)
- **Vanilla JavaScript** — no frameworks or libraries
- **Google Fonts** — Poppins (headings) & Karla (body)

## 🚀 Running Locally

```bash
git clone https://github.com/Forrever12-byte/restaurant-landing-page-template.git
cd restaurant-landing-page-template
npm install
npm run build
```

Then open `index.html` in your browser (or use a Live Server extension).
